## 2. 设计原则

1. **内容区优先**：每个工具只有三条横带——36px 命令栏、26px 面板头、24px 状态栏。
2. **一处一个入口**：同一操作只出现一次；低频操作收进 `⋯` 菜单；全部操作可被 `⌘K` 搜到。
3. **反馈不挤布局**：报错、统计一律进状态栏；输入无效时保留上一次结果并置灰。
4. **状态可见**：当前模式用滑块指示；选项用 chip 的开/关态；差异用 `3 / 12` 计数。
5. **动画只服务理解**：位置变化用平移，出现消失用淡入+轻微位移，全部走合成层，不超过 300ms。

## 3. 外壳

- **图标轨道 48px**：默认只露图标；悬停向右展开到 200px，**覆盖**内容而不是挤压内容（零重排）。
- 轨道头部有「固定」按钮：固定后常驻 200px，内容区平滑让位。
- 活动指示器是一个独立滑块，切换工具时**弹性滑动**到新位置，而不是各项自己高亮。
- 底部：外观与主题（6 色板 × 明/暗）。
- **命令面板 `⌘K`**：工具、主题、明暗、侧栏全部可搜，中英文别名都能命中（`th` → 主题）。
- 快捷键：`1/2/3` 切工具，`F7 / ⇧F7` 对比上/下一处。
- **窄屏（<860px）**：分栏自动改上下堆叠，次要选项收起，轨道保持图标态。

## 5. 动画规范

| 场景 | 动画 | 时长 / 曲线 |
| --- | --- | --- |
| 切换工具 | 旧页淡出、新页淡入并上浮 6px；轨道指示器弹性滑动 | 180ms ease-out / 280ms spring |
| 分段控件 | 滑块 `translateX` + `width`，弹性回弹 | 280ms spring |
| 面板视图（文本/树/表格） | 淡入 + 上浮 5px | 180ms |
| 树节点展开 | `grid-template-rows: 0fr → 1fr` + 箭头旋转 | 280ms ease-out |
| 下拉菜单 / 命令面板 | 缩放 + 位移淡入，带轻微回弹 | 280ms spring |
| 轨道展开 | 宽度过渡 + 文字淡入错峰（60ms 延迟） | 280ms ease-out |
| 对比跳转 | 目标行底色闪烁 | 1s |
| 输入无效 | 旧结果淡出到 38% 并降低饱和度 | 280ms |
| 按压 | 缩放到 95% | 120ms |

约束：只动 `transform` / `opacity` / `filter`；不动 `top/left`；`prefers-reduced-motion` 下全部取消。

## 6. 落地计划（建议分阶段，每阶段可独立验收）

| 阶段 | 内容 | 风险 |
| --- | --- | --- |
| P1 外壳 | 图标轨道 + 悬停展开 + 固定；命令栏/状态栏/面板头三条横带的公共组件；响应式 | 低 |
| P2 JSON | 命令栏重做、视图切换、JSONPath 查询、键排序、宽松修复、状态栏、错误定位 | 中（需引入/自写 JSONPath） |
| P3 对比 | chip 选项、计数导航、统计、忽略键顺序 | 中（语义对比要处理排序） |
| P4 SQL | 方言 / 大小写 / 缩进、复制为代码、统计 | 中（需确认现有格式化器能力） |
| P5 其余 14 个工具 | 套用同一套公共组件，逐个迁移 | 低，但量大 |

## 7. 设计稿中仍是“示意”的部分

- 编辑器是轻量自写版（行号 + 高亮 + 文本框），正式实现仍使用 Monaco。
- SQL 方言目前只影响状态栏文案，未改变格式化结果。
- 「忽略键顺序」「复制为 TypeScript / JSON Schema」「关系图」未在设计稿里实现，仅在方案中标注。
