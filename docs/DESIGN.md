# Dev Toolbox 设计规范

目标：**紧凑、优雅、高性能、可离线**。内容区优先，界面元素让位于内容。

## 1. 设计原则

| 原则 | 落地方式 |
| --- | --- |
| 内容优先 | 工具栏 36px、侧栏 204px（可折叠到 52px）、内容区间距 8px |
| 高性能 | 动画只用 `transform` / `opacity`；禁用 `backdrop-filter`；`transition-all` 收窄为具体属性 |
| 离线可用 | PWA 完整预缓存（含 Monaco）；无外链字体；统计脚本离线时跳过 |
| 友好交互 | 搜索 / 固定 / 最近使用 / 命令面板 / 键盘快捷键 / 焦点环 |
| 可访问 | 尊重 `prefers-reduced-motion`；键盘焦点环；弹层可 Esc 关闭 |

## 2. 设计令牌（`src/style.css`）

### 2.1 颜色
颜色 = **色板（`data-palette`）× 明暗（`.dark`）**，两者正交，共 6 × 2 = 12 种组合。

色板只需声明 6 个变量，其余颜色（背景、卡片、边框、柔和色等）由公式推导：

| 变量 | 含义 |
| --- | --- |
| `--nh` | 中性色相：背景/边框带一点主色倾向，整体更协调 |
| `--ph` / `--ps` / `--pl` | 主色的色相 / 饱和度 / 亮色模式明度 |
| `--psd` / `--pld` | 暗色模式主色的饱和度 / 明度 |

| 色板 | id | 气质 |
| --- | --- | --- |
| 靛蓝（默认） | `indigo` | 沉稳、专业 |
| 翠绿 | `emerald` | 清爽、护眼 |
| 玫瑰 | `rose` | 活泼、醒目 |
| 琥珀 | `amber` | 温暖、复古 |
| 海洋 | `ocean` | 冷静、通透 |
| 石墨 | `graphite` | 近乎单色、极简 |

语义色：`primary` `secondary` `muted` `accent` `destructive` `success` `warning` `border` `ring`，
统一以 `hsl(var(--x) / <alpha>)` 使用，Tailwind 的 `bg-primary/10` 等透明度写法全部可用。

**新增色板三步**：`src/utils/palettes.ts` 登记 → `style.css` 加一行变量 → 两份 locale 补名称；
同时同步 `public/theme-init.js` 里的合法 id 列表。

### 2.2 尺寸与间距

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| 根字号 | 15px | 配合下调的字号刻度 |
| `text-xs / sm / base` | 11 / 13 / 14px | 比 Tailwind 默认小一档 |
| `--toolbar-h`（`h-toolbar`） | 36px | 侧栏头部与每个工具的顶部工具栏等高，横向对齐 |
| `--radius` | 8px | `rounded-lg`；`md` = 6px，`sm` = 4px |
| 内容区外边距 | 8px（`p-2`） | 面板之间 `gap-2` |
| 面板内边距 | 12px（`p-3`） | 表单类卡片 |
| 侧栏条目高度 | 32px | 图标 16px |

### 2.3 阴影
只有两档：卡片用 `shadow-sm`，浮层用 `shadow-pop`（`--shadow-pop`，随明暗自动变化）。

## 3. 动效规范

所有动效参数集中在 `:root`，禁止在组件里随手写时长和曲线。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-fast` | 120ms | hover、按压 |
| `--dur-base` | 180ms | 淡入淡出、页面切换 |
| `--dur-slow` | 280ms | 弹层、侧栏折叠、列表入场 |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 默认：出场快、收尾柔 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 弹层、色板选中，带轻微回弹 |

可复用类：

| 类名 | 效果 |
| --- | --- |
| `page-*`（transition） | 路由切换：上浮 6px + 淡入；离场淡出且不占布局 |
| `fade-*` | 遮罩淡入淡出 |
| `pop-*` | 弹层：下方 8px 缩放弹出 |
| `.stagger` | 子元素错峰入场（每项相隔 25ms） |
| `.press` | 按下缩放到 94% |
| `.skeleton` | 骨架屏微光 |
| `.route-progress` | 顶部路由加载细条，**超过 150ms 才出现**，快速切换不闪 |

铁律：
1. 只动 `transform` / `opacity`，不动 `width / height / top / left`（侧栏折叠是唯一例外，且拖拽时关闭过渡）。
2. 动画时长不超过 300ms。
3. `prefers-reduced-motion` 下全部动画瞬间完成（全局已处理，无需单独适配）。

## 4. 布局

```
┌────────┬──────────────────────────────────────────┐
│ Logo ⟨ │ [图标 工具名] │ 操作 │ 选项 …      │ 36px │  ← 工具栏
│ 搜索 / ├──────────────────────────────────────────┤
│ 已固定 │                                          │
│ 最近   │               内容区                      │
│ 全部   │         （面板间距 8px，占满）              │
│ 设置   │                                          │
└────────┴──────────────────────────────────────────┘
   204px
```

- 侧栏：搜索（按 `/` 聚焦，Enter 直达第一个结果）→ 已固定 → 最近使用 → 全部工具 → 设置。
- 折叠态 52px，只显示图标，悬停显示 title；折叠时搜索变为命令面板入口。
- 拖拽右边缘调整宽度（176–320px），双击恢复默认。
- 已移除白板（Excalidraw）及其全部依赖（含 React），安装包与预缓存明显变小。

## 5. 交互清单

| 快捷键 | 行为 |
| --- | --- |
| `⌘/Ctrl + K` | 命令面板（模糊匹配：`jsn` → JSON 工具） |
| `/` | 聚焦侧栏搜索 |
| `⌘/Ctrl + /` | 新手引导 |
| `Esc` | 关闭设置 / 命令面板 / 清空搜索 |
| `↑ ↓ Enter` | 命令面板导航与进入 |

命令面板空查询时的排序：已固定 → 最近使用 → 其余。

## 6. 性能与离线

- **首屏防闪**：`public/theme-init.js`（外部脚本，符合 CSP `script-src 'self'`）在首次绘制前设置明暗与色板。
- **渲染成本**：全局禁用 `backdrop-filter`；内容区 `contain: layout style`；侧栏拖拽用 rAF 节流。
- **离线**：Service Worker 完整预缓存全部产物（含 Monaco 约 3.3MB），首次访问后立刻断网也能使用所有工具；
  系统字体栈，无外链字体；访问统计仅在联网且浏览器空闲时加载。
- **本地存储键**：`theme-mode` `ui-palette` `editor-theme` `nav-pinned` `nav-recent` `sidebarWidth` `sidebarCollapsed`。
